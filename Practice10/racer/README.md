# Racer

A simple racer game made with pygame.

## Features
- Player car movement
- Enemy cars
- Random coins
- Coin counter in the top right corner
- Score counter
- Speed increase over time

## Controls
- Left Arrow = move left
- Right Arrow = move right
- Up Arrow = move up
- Down Arrow = move down
- Q = quit
