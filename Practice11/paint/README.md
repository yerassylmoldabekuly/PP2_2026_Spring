# Paint

This project is a simple paint application made with pygame.

## Features
- Brush
- Rectangle
- Circle
- Eraser
- Square
- Right triangle
- Equilateral triangle
- Rhombus
- Color selection

## Controls
- 1 = Brush
- 2 = Rectangle
- 3 = Circle
- 4 = Eraser
- 5 = Square
- 6 = Right triangle
- 7 = Equilateral triangle
- 8 = Rhombus
- R = Red
- G = Green
- B = Blue
- K = Black
- C = Clear
- Q / ESC = Quit
